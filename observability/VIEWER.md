# 뷰어 — 에이전트 흐름 · 스킬·도구·비용

> `node observability/viewer/server.mjs` → `http://127.0.0.1:8790`. 의존성 없음, 읽기 전용(GET만).
> 설정: `TRACES_DIR`(기본 `traces`), `TRACE_VIEWER_HOST`(기본 `127.0.0.1`), `TRACE_VIEWER_PORT`(기본 8790).

## 화면
- **에이전트 흐름** (`/`)
  - 최근 실행 목록. 오류만 보기 필터. 처음엔 가장 최근 오류 실행을 연다.
  - **토폴로지**: 에이전트 전체를 고정 지도로 그리고, 이번 실행이 쓴 노드에 불을 켠다. 상태는 완료·실패·미사용·꺼짐.
    노드마다 역할 문구가 항상 보여서 누르지 않아도 무엇을 하는지 알 수 있다. 끌어서 이동, +/−/맞춤 버튼으로 확대.
    마우스 휠 확대는 일부러 뺐다(페이지 스크롤을 빼앗아 불편).
  - **순서도**: 열 = 누가(요청·워커·조회·저장·웹·응답), 행 = 언제. 같은 도구 연속 호출은 한 줄(×횟수).
    위에 단계 요약 줄, 첫 오류 자동 선택, 화살표 키 이동, 휴대폰은 한 열.
  - **단계 상세**: 입력·결과·오류·모델·토큰·비용. "기록 없음 (경로상 거침)" = 호출 기록은 없지만 앞뒤 단계로 보아 지나간 부분.
  - **비용 내역**: 아래 띠의 비용 칸을 누르면 토큰 종류별 금액과 "왜 이만큼"(이어받은 대화·턴 수·생각 토큰) 설명.
  - Langfuse가 연결돼 있으면 같은 실행을 Langfuse에서 여는 링크.
- **스킬·도구·비용** (`/usage`): 7·30·90일 기준 비용 내역(토큰 종류별·작업별), 보유 스킬과 사용 횟수, 도구별 사용·오류·마지막 사용.

## 구성도 고치기 (`topology.json`)
- `lanes`: 순서도의 열. `{key, name, desc}`
- `nodes`: `{id, c, r, icon, name, role, ns, lane, match?, via?, special?}`
  - `c`·`r`: 격자 칸(열·행). `role`은 노드에 항상 보이는 한 줄 설명이다. 사용자 말로 쓴다.
  - `match`: span을 이 노드에 붙이는 규칙. `{kind, name, trigger}` 각각 정규식. **위에서부터 처음 맞는 노드**가 가져가므로 넓은 규칙(기타 도구)은 맨 아래에.
  - `via`: 호출 기록이 따로 없는 단계(권한 가드, 저장소 등). 나열한 노드 중 하나가 쓰였으면 "거침"으로 켠다.
  - `special: "langfuse"`: Langfuse가 설정돼 있으면 전송 상태, 아니면 "꺼짐".
  - `icon`: trigger·clock·gate·bot·brain·config·plug·read·write·web·db·send·chart·block
- `groups`: 노드 묶음 상자 `{label, c0, c1, r0, r1}`
- `edges`: `[from, to, label, mode, ax, bx, onIf]`. 선은 칸 사이 틈으로만 지나간다.
  - mode `R` 오른쪽→왼쪽(같은 행) · `D` 아래→다음 행 위 · `L` 아래로 내려가 왼쪽 옆으로 · `T` 위쪽 틈으로 넘어감 · `U` 아래쪽 틈으로 돌아 아래에서 들어감
  - `ax`·`bx`: 출발·도착 노드 폭에서의 위치(0~1). `onIf`: 이 노드가 쓰였을 때만 선을 켠다.
- 고친 뒤 `node --test observability/test/`로 모든 선의 노드가 있는지 확인한다.

## 원격 접속 (휴대폰 등)
뷰어는 `127.0.0.1`에만 연다. 공유기·공개 인터넷에 열지 않는다. 다른 기기에서 볼 때는 사설망 터널을 쓴다.
```bash
tailscale serve --bg --https=8790 http://127.0.0.1:8790   # 끄기: tailscale serve --https=8790 off
```
`TRACE_VIEWER_HOST=0.0.0.0`은 신뢰하는 망에서만 쓴다. 뷰어에는 로그인이 없다.

## 앱 대시보드에 넣기
앱에 이미 웹 서버가 있으면 `viewer/`의 html·js·css를 그대로 서빙하고 `/api/*` 다섯 개(`config`·`topology`·`traces`·`traces/:id`·`usage`)만 같은 모양으로 돌려주면 된다. 모양은 `viewer/server.mjs`가 기준이다.
